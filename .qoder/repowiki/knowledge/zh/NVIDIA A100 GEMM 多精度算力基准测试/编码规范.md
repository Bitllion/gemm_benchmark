- 所有 CUDA/cuBLAS API 调用均通过 CUDA_CHECK / CUBLAS_CHECK 宏包裹，失败时输出文件名、行号、调用名和错误信息后直接 exit(EXIT_FAILURE)。
- 每种数据类型的测试遵循相同模式：分配 d_A/d_B/d_C 设备内存 → 主机端初始化随机矩阵 → cudaMemcpy 到设备 → 调用 run_cublas_gemm(handle, label, N, a_type, b_type, c_type, compute_type, &alpha, &beta, ...) → 释放设备内存。
- 计时统一采用 cudaEvent_t 事件机制：warmup 阶段不计时，正式阶段记录 start/stop 事件并通过 cudaEventElapsedTime 计算平均耗时，再以 gemm_flops(N,N,N)/(avg_ms*1e6) 换算 GFLOPS。
- FP8 相关代码通过独立的 convert_* 内核完成 FP16↔FP8 转换，主 GEMM 内核使用 TILE=32 的分块策略配合 __shared__ float As/TBs[TILE][TILE+1] 缓存，体现统一的 tiled GEMM 实现风格。
