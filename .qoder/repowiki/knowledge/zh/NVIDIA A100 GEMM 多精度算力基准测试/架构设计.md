单文件 CUDA 程序（gemm_benchmark.cu）+ Makefile 构建系统。
- 错误处理：通过 CUDA_CHECK / CUBLAS_CHECK 两个 do-while 宏统一封装 CUDA/cuBLAS API 调用失败检查并退出。
- 核心执行路径：main() 解析命令行参数（矩阵大小、迭代次数），打印 GPU 信息后对每个尺寸循环调用 run_cublas_gemm() 执行 6 种 cuBLAS 精度测试，再单独调用 run_fp8_gemm() 执行自定义 FP8 内核测试。
- 计算内核：FP8 测试使用三个独立 kernel——convert_f16_to_fp8_e4m3_kernel、convert_fp8_e4m3_to_f16_kernel、fp8_gemm_kernel（TILE=32 分块 + shared memory 缓存），以 FP8 存储 + FP16 计算模拟 A100 原生不支持的 FP8。
- 依赖方向：.cu → cublas_v2.h / cuda_fp16.h / cuda_bf16.h / cuda_fp8.h；Makefile 通过 -lcublas 链接 cuBLAS 库，目标架构固定为 sm_80（A100）。
- 构建产物：单一可执行文件 gemm_benchmark，无子模块或动态库。
