### GEMM
- 定义：通用矩阵乘法（General Matrix Multiplication），即 C = α·A×B + β·C，是本项目基准测试的核心算子，用于测量不同数据精度下的 GPU 计算能力。FLOPs 按标准公式 2×M×N×K 计算。
- 别名：矩阵乘法、GEMM 算子

### Tensor Core
- 定义：NVIDIA GPU 上的专用矩阵计算单元，支持 FP16/BF16/TF32/INT8 等低精度格式的高吞吐计算。A100 上 FP64 也可通过 Tensor Core 运行。官方峰值包含 2:4 稀疏加速，Dense 实际约为标称值的 50%。
- 别名：张量核心、TC

### Ampere 架构
- 定义：NVIDIA 第 8 代 GPU 架构（Compute Capability 8.0），代表型号为 A100。支持 TF32、FP16、BF16、INT8 Tensor Core 计算，但不原生支持 FP8。
- 别名：sm_80、A100 架构

### Hopper 架构
- 定义：NVIDIA 第 9 代 GPU 架构（Compute Capability 9.0），代表型号 H100。首次原生支持 FP8 E4M3/E5M2 格式，是真正硬件级 FP8 计算的必要条件。
- 别名：sm_90、H100 架构

### Ada Lovelace 架构
- 定义：NVIDIA 消费级第 4 代 GPU 架构（Compute Capability 8.9），代表型号 RTX 4090/L40。同样原生支持 FP8 计算，与 Hopper 并列作为 FP8 硬件平台。
- 别名：sm_89、RTX 4090 架构

### Warmup
- 定义：预热阶段，在正式计时前执行若干次 GEMM 调用以触发 cuBLAS 的算法选择和内核编译，避免将初始化开销计入性能测量。默认 5 次。
- 别名：预热、warmup iters

### Dense GEMM
- 定义：密集矩阵乘法，不涉及结构化稀疏。本项目所有测试均为 Dense 模式，无法利用 NVIDIA 官方峰值中 2:4 稀疏加速带来的倍率提升。
- 别名：密集 GEMM、稠密矩阵乘法
