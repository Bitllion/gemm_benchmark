## CUDA 事件计时机制

CUDA 事件计时是 GPU 性能测量的核心机制。在 GEMM 基准测试中，我们使用 `cudaEventRecord` 和 `cudaEventSynchronize` 来实现精确的时间测量。

### 事件创建与销毁
```cpp
// 创建 CUDA 事件用于计时
cudaEvent_t start, stop;
cudaEventCreate(&start);
cudaEventCreate(&stop);
```

### 事件记录机制
```cpp
// 记录开始事件
cudaEventRecord(start, stream);
// 执行内核函数
kernel<<<grid, block>>>(...);
// 记录停止事件
cudaEventRecord(stop, stream);
```

### 同步与时间计算
```cpp
// 等待事件完成并计算时间差
cudaEventSynchronize(stop);
float milliseconds = 0;
cudaEventElapsedTime(&milliseconds, start, stop);
```

## 内核执行时间测量

准确的内核执行时间测量需要避免预热和同步开销的影响。GEMM 基准测试采用了以下策略：

### 预热阶段
在执行正式测量之前，进行多次预热运行以确保 GPU 达到稳定状态：
```cpp
// 预热阶段
for (int i = 0; i < warmup_runs; i++) {
    kernel<<<grid, block>>>(...);
}
cudaDeviceSynchronize();
```

### 多次测量取平均
为了获得更准确的结果，进行多次测量并计算平均值：
```cpp
std::vector<float> timings;
for (int i = 0; i < num_runs; i++) {
    // 记录开始时间
    cudaEventRecord(start, stream);
    
    // 执行内核
    kernel<<<grid, block>>>(...);
    
    // 记录结束时间
    cudaEventRecord(stop, stream);
    cudaEventSynchronize(stop);
    
    float elapsed;
    cudaEventElapsedTime(&elapsed, start, stop);
    timings.push_back(elapsed);
}
```

### 异常值处理
移除极端异常值以提高测量准确性：
```cpp
// 排序并移除异常值
std::sort(timings.begin(), timings.end());
float median_time = timings[timings.size() / 2];
```

## 吞吐量计算方法

### GFLOPS 计算
对于 GEMM 操作，GFLOPS（每秒十亿次浮点运算）的计算公式为：
```
GFLOPS = (2 * M * N * K) / (time_in_seconds * 1e9)
```

其中：
- M, N, K 是矩阵维度
- time_in_seconds 是以秒为单位的时间
- 系数 2 表示乘加操作的浮点运算次数

### 内存带宽分析
内存带宽利用率计算：
```
带宽利用率 = (实际数据传输量 / 理论最大带宽) * 100%
```

## 性能基准测试最佳实践

### 多次运行策略
- **运行次数**：建议至少运行 10 次以获得稳定的统计结果
- **预热次数**：预热 5-10 次以确保 GPU 达到稳定状态
- **间隔时间**：每次运行之间添加适当的延迟以避免缓存影响

### 统计计算方法
```cpp
// 计算平均值
float mean = std::accumulate(timings.begin(), timings.end(), 0.0f) / timings.size();

// 计算标准差
float variance = 0.0f;
for (float t : timings) {
    variance += pow(t - mean, 2);
}
float std_dev = sqrt(variance / timings.size());
```

### 环境控制
- **GPU 频率锁定**：确保 GPU 频率在整个测试过程中保持稳定
- **温度监控**：监控 GPU 温度以避免热节流影响
- **进程隔离**：确保没有其他进程干扰测试结果

### 结果验证
- **一致性检查**：多次运行的结果应该具有良好的一致性
- **异常检测**：识别并排除明显异常的测量结果
- **基准对比**：与已知基准结果进行比较验证

## 代码示例实现

### 完整的性能测量框架
```cpp
class PerformanceBenchmark {
private:
    cudaEvent_t start_event_;
    cudaEvent_t stop_event_;
    std::vector<float> timing_results_;
    
public:
    PerformanceBenchmark() {
        cudaEventCreate(&start_event_);
        cudaEventCreate(&stop_event_);
    }
    
    ~PerformanceBenchmark() {
        cudaEventDestroy(start_event_);
        cudaEventDestroy(stop_event_);
    }
    
    void runBenchmark(int num_warmup, int num_runs) {
        // 预热阶段
        for (int i = 0; i < num_warmup; i++) {
            executeKernel();
        }
        
        // 正式测量
        for (int i = 0; i < num_runs; i++) {
            measureExecutionTime();
        }
    }
    
    float getMeanTime() {
        return std::accumulate(timing_results_.begin(), 
                              timing_results_.end(), 0.0f) / 
               timing_results_.size();
    }
};
```
